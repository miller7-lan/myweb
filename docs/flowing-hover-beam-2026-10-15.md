# 星球悬停流动虚线 · 本地验收

## 实现与回退

- 分支：codex/flowing-hover-beam；修改前标签 hover-beam-before-2026-10-15 指向 970fa84。
- 仅修改 LockBeam 的呈现方式，沿用原有星核至星球的端点、圆柱宽度、主题色和单网格。
- 在片元着色器中将屏幕坐标投影到连线方向，按 CSS 像素划分 10px 线段、6px 间隙和约 1px 柔化边缘，使用真实渲染 DPR 换算。
- 相位按 delta 时间推进：Cinematic 22px/s、Focus 14px/s。切换目标重置相位，离开时冻结图案并淡出。
- Silent 与系统减少动态效果偏好下停止相位和亮度脉动；运行期间偏好变化即时响应。
- 使用实际 ShaderMaterial.uniforms 更新每帧参数，避免渲染器复制初始化参数后数值变化未传入实际材质。

## 验收清单与结果

- 五颗星球分别悬停：连线显示、主题色切换、端点与方向正确；保持细线和清晰间隙。
- 流速测量：以场景时钟与实际材质相位测得 Cinematic 22px/s、Focus 14px/s。
- 静态模式：Silent 相位差为 0；减少动态效果稳定后相位差为 0，透明度差低于 1e-8，恢复偏好后继续流动。
- 边界场景：快速切换五个目标、移出后淡出不可见、进入主题后不可见、返回首页重新悬停可见。
- 桌面 1440×960、手机 390×844 / DPR 2：Canvas 完整覆盖视口，无页面横向溢出，手机实际星球命中触发正常。
- 未发现着色器编译或页面运行错误。最初本地未启动 API 服务时有已有代理 502；启动现有服务后未记录失败请求。
- 最终构建、lint 与作品内容检查结果见本轮会话日志；未新增依赖、公共接口或自动化发布行为。
